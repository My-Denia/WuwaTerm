# Lucide icons

These are unmodified SVGs from [lucide-icons/lucide](https://github.com/lucide-icons/lucide),
pinned to commit `ee8e10d746a10907205366cfd984922f0c58939a` (retrieved
2026-11-06). The exact source for an icon is
`https://raw.githubusercontent.com/lucide-icons/lucide/ee8e10d746a10907205366cfd984922f0c58939a/icons/<name>.svg`.

The complete upstream [LICENSE](LICENSE) covers the Lucide ISC license and,
for the Feather-derived icons listed there, the Feather MIT notice. The
`SHA256SUMS` file records the retrieved SVGs and the upstream license.

The client renders the upstream `currentColor` stroke using its active theme;
the SVG files themselves remain unchanged. The client names `history` and
`waves` resolve to the upstream `rotate-ccw-clock` and `waves-horizontal`
files respectively.
